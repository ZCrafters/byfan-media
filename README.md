# byfan-media

Host publik untuk media yang dijadwalkan ulang ke Threads @byfanwilliams.

File di `posts/<shortcode>/` memakai nama hash SHA-256 16 karakter, supaya tidak ada nama orang atau proyek yang terekspos. `media_index.json` memetakan shortcode ke tanggal, caption asli, dan URL mentah tiap file.

Jangan menaruh kredensial, cookie, atau file kerja di repo ini.
